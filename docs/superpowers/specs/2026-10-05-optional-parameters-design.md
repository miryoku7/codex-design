# 初回制作の調整パラメータを任意にする

初回はHTML/CSSの制作と比較を既定にする。ユーザーが指定した場合は最初からパラメータを作り、作成後も会話から任意の案へ追加できる。削減する工程はパラメータの設計・バインド・検証。初回制作の短縮幅は未計測。

- v2の `sources` はHTML/CSSを必須、controlsを任意とする。パラメータなしは `tokens: {}`、独自tweaksなし。追加時はcontrols参照と定義、現在値・リセット値を保存する。
- v1のportable保存でも空tokensを認める。空以外の基本tokensは従来の6項目を検証する。既存作品の形式と操作は維持する。
- 操作欄は宣言された項目のみ表示する。項目なしでは基本設定とリセットを非表示にし、メモ・採用・書き出しを維持する。
- controlsなしのexportはcontrolsファイルを生成しない。キット抽出は存在する宣言だけを使う。既存のキットは1個以上のトークンを必要とする。
- 追加はAstraが現在の見た目を既定値として対象CSSをバインドする。保存済み状態を読んでsnapshotを残し、既存値・メモ・採用・他案を保持する。ライブラリは最新版exportとrevision付きpushを使う。
- 自動プレビュー検査は宣言されたrange数と描画数を照合し、0個も許容する。未宣言のパラメータをテストのために追加しない。

検証: local D1/API/CLIの往復、controlsなしの保存・複製、後付けとリセット、競合時の保持、既存runtime、型検査、対象JavaScript構文、実ブラウザの非表示→追加→調整を専用fixtureで確認する。現用作品・DBは変更しない。
